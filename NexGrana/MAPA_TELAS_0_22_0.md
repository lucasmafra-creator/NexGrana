# Mapa de telas — NexGrana 0.22.0

| Área | Conteúdo | Caminhos principais |
| --- | --- | --- |
| Início | saldo do perfil, futuro, panorama individual/familiar, atenção e Trilha | Transações, Saúde financeira, Nex |
| Transações | renda, despesas, parcelas, filtros e edição | Início, Planejamento |
| Planejamento | metas, aquisições, investimentos educativos e Renda Extra | Nex contextual, Início |
| Mercado | carrinho, conferência da nota, histórico e Achados separado | oferta externa com aviso |
| Nex | chat livre, até cinco fixados, ferramentas locais e modo online opt-in | Voltar explícito no mobile |
| Mais | perfil/espaço, tutorial, privacidade, sincronização, backup e QA | qualquer área pelo menu |
| Painel Achados | aplicação web separada, exclusiva de administrador | Supabase com RLS/auditoria |

Mobile mantém cinco destinos: Início, Transações, Planejamento, Mercado e Nex. “Mais” fica no cabeçalho/atalho de configurações. Desktop usa sidebar sem mudar as fontes de dados.
