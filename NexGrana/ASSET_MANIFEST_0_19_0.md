# Assets do Nex — 0.19.0

O runtime usa somente o master canônico transparente e derivados otimizados por papel. GIFs antigos degradados foram removidos das pastas de runtime que não eram referenciadas.

- `nex_hd.png`: master RGBA 1254×1254.
- `nex_hero.png`: uso hero.
- `nex_card.png`: cards.
- `nex_dock.png`: dock/sidebar.
- `nex_avatar.png`: bolhas/avatar.

`src/assets/nex/manifest.json` é a fonte de caminhos ativos.

IMPORTANTE: os estados atuais usam a mesma arte canônica com micro-movimentos. Isso melhora nitidez e performance, mas **não equivale** ao pack final de animações 3D/rig. A próxima etapa de arte deve produzir estados realmente distintos com a mesma identidade canônica e validar Rive/WebP/sprites em Windows e Android antes de escolher tecnologia.
