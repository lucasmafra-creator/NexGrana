# Roadmap

- **A — Fundação:** implementada localmente; Auth real/Postgres remoto ainda são gates de produção.
- **LiveOps 0.2 — continuidade operacional:** implementado como ponte entre A e B; worker, feedback, tasks e checks contínuos.
- **B — Operação manual completa:** Collector ZIP, anexos/evidências, estados completos de QA/reteste e fluxo SAC.
- **C — Releases/segurança:** GitHub read-only/webhooks, CI ligado ao painel, security gate, incidentes e release registry.
- **D — Agentes assistivos:** Product Analyst + Release Auditor primeiro, em modo read-only/rascunho.
- **E — Expansão:** Engineering/QA/SAC assistivos, marketing agregado e novos produtos.

A existência de worker e automações não marca B/C/D como concluídas sem os gates definidos no Prompt Mestre.
